# BPVS Admin V4
Separate DoE and manufacturer routes, explicit module tables and local actions. Shared UI primitives and pagination hook only. Reports read-only. Dashboard sample data. Existing API and theme retained.
Copy .env.example to .env.local, npm install, npm run typecheck, npm run dev.
Search is current page only. Details are explicit field dialogs, not standalone detail routes. Production and user option lists are limited to first 100. No live API or production build verified.
